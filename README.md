🧑‍💼 Employee Management System (EMS)

A Python-based **Employee Management System** that allows admin and users to manage employee records efficiently.

---

## 📌 Features

* 🔐 Admin Dashboard
* 👨‍💼 User Dashboard
* 🗄️ Database Connection
* 📋 Employee Data Management
* ⚡ Simple CLI-based system

---

## 📁 Project Files

* `main.py` → Entry point of the application
* `admin_dashboard.py` → Admin functionalities
* `user_dashboard.py` → User functionalities
* `connection.py` → Database connection setup
* `__init__.py` → Package file

---

## 🚀 How to Run

1. Download or clone the repository:

```
git clone https://github.com/suriyaks2007/EMS.git
```

2. Go to project folder:

```
cd EMS
```

3. Run the project:

```
python main.py
```
